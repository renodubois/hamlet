# Architectural decisions

Store architectural decision records in this directory. Create a record only when a consequential decision has actually been made; this overview is not an ADR.

New records use the filename template `NNNN-slug.md`, starting at `0001` and incrementing the highest existing numbered record. Ignore this overview when numbering.

See [the ADR format](../../.agents/skills/domain-modeling/ADR-FORMAT.md) for the format and decision criteria, and [domain guidance](../agents/domain.md) for consumer rules.
