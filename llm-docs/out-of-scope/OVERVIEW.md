# Rejected feature requests

Store confirmed enhancement rejections in this directory, one Markdown record per concept. This overview is not a rejection record; exclude it when matching incoming requests against prior rejections.

New records use the filename template `<concept>.md`. Create a record only after a maintainer rejects a request, not for bugs or features that are already implemented.

See [the triage knowledge-base guide](../../.agents/skills/triage/OUT-OF-SCOPE.md) for the record format and workflow.
